# 2026-10-10 · 오버레이 앱 7종 만들기

하루 동안 폴스타 4에 올릴 사이드로드 오버레이 앱 7종을 만들었다. 모두 지니(Genie)와 함께.

## 만든 앱
| 앱 | 패키지 | 핵심 기능 |
|---|---|---|
| 🧭 기어 | com.jangbc.gearoverlay | R N D P H 표시, 변속·오토홀드 알람 |
| ⚡ 전비 | (trip) | 바퀴기반 주행거리·전비·배터리 |
| 🚦 과속 경고 | com.jangbc.speedoverlay | 제한 속도 초과 시 빨강 + 비프 |
| 📺 유튜브 | com.jangbc.ytsoverlay | WebView로 유튜브 영상 재생 |
| 🌐 웹 | com.jangbc.weboverlay | 아무 웹사이트 + 북마크 관리 |
| 🔗 숏컷 독 | com.jangbc.shortcutoverlay | 설치앱 바로가기 독 |
| 📷 주차 스냅샷 | com.jangbc.parksnap | P 진입 시 촬영 → 텔레그램 전송 + 위치 |

## 공통 기술
- **targetSdk 22** → Android 12 기반 AAOS에서 `SYSTEM_ALERT_WINDOW` 자동 부여 (오버레이 권한 화면이 없음)
- **리플렉션 Car API** — `android.car` 스텁에 컴파일하지 않고 런타임 조회 (`Class.forName`)
- **TYPE_APPLICATION_OVERLAY** 포그라운드 서비스 + SharedPreferences 진단 로그
- JVM 단위 테스트 → `aapt dump badging` 검증 → zip 전송 (사이드로드)

## 시행착오 (요약)
- **오버레이 창이 상태바에 가림** — 창은 화면 맨 위에 배치되고 차 상단바가 덮음 → y를 상태바 높이 아래로 강제해야 헤더가 잡힘
- **MATCH_PARENT 창은 `lp.y` 무시** — 전체화면 여백은 창 안쪽 뷰의 topMargin으로
- **유튜브 앱 임베드 불가** — 다른 앱 UI는 오버레이에 못 넣음 → 웹버전(WebView)으로
- **도어 신호 차단** — `DOOR_POS`는 Signature|Privileged 권한 → 서드파티 앱 불가 → 트리거를 "P 기어 진입"으로 대체
- **텔레그램 전송 3연타 실패** — ①봇과 대화 미시작(chat not found) ②차에서 토큰 오타(401) ③캡션 UTF-8 깨짐(400)

## 결과
7종 모두 실차 동작. 특히 주차 스냅샷은 P 넣으면 사진 + 위치(지도)가 텔레그램으로 자동 도착.
