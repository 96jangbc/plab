# 🚦 과속 경고

현재 속도를 크게 보여주고, 정한 제한을 넘으면 **색과 소리로 경고**하는 오버레이입니다.

## 이 앱은?
계기판 속도를 계속 보기 어려울 때, 화면에 큰 숫자로 띄우고 **제한 속도를 넘으면 빨갛게 + 삐** 소리로 알려줍니다. (단속카메라 위치가 아니라 "내 속도" 기준)

## 주요 기능
- 현재 속도(km/h) 크게 표시
- 제한 초과 시 **화면 빨강 + 비프음**(3초마다)
- 제한 설정: 30/50/60/80/100 · ±5 (실제 경고는 허용오차 +3 km/h부터)

## 사용법
1. 앱 실행 → 원하는 제한 선택 → 오버레이 켜기
2. 주행 중 제한을 넘으면 자동 경고

## 기술 포인트
- 속도: `PERF_VEHICLE_SPEED`(m/s) / `PERF_VEHICLE_SPEED_DISPLAY`(km/h) 중 큰 값 사용
- ※ 카메라 앞에서만 경고하는 방식이 아니라, 제한만 넘으면 알려줌
