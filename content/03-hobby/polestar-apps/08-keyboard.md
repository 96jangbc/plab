# ⌨️ 오버레이 키보드

**차량 기본 키보드를 화면 절반 크기의 떠 있는 키보드로.** 위치·크기·투명도까지 실시간으로 조절합니다.

## 이 앱은?
폴스타4 기본 키보드는 화면 폭을 **전부** 차지합니다. 검색창에 한 글자 입력하려는데 화면 아래가 통째로 가려지죠. 이 앱은 **화면 폭의 절반 크기**로 떠 있는 키보드를 띄워, 입력하면서도 뒤 화면을 함께 볼 수 있게 합니다.

사진처럼 검색창 위에 **반폭 카드 형태**로 나타나고, 필요하면 95%까지 확장됩니다.

![오버레이 키보드 실행 화면](../../assets/img/kboverlay-1.jpg)

## 주요 기능
- **반폭(1/2) 플로팅 키보드** — 기본 50%, 확장 시 95%
- **한글 조합 지원** — 초성·중성·종성 조합, 복합 모음(ㅘㅙㅚㅝㅞㅟㅢ), 겹받침(ㄳㄵㄺㅄ 등)
- **⇧ 쌍자음 연동** — 누르면 자판이 `ㅃㅉㄸㄲㅆ`으로 실제 변경되고 활성 키가 색으로 강조
- **8가지 표시 설정** — 테마 / 글씨 굵기 / 글씨 크기 / 가로 위치 / 하단 여백 / 불투명도 / 폭 / 키 높이
- **모든 설정 실시간 반영** — 슬라이더를 움직이면 키보드가 즉시 바뀜

## 사용법
1. 앱 실행 → **"키보드 활성화"** → 목록에서 "오버레이 키보드" 켜기
2. **"오버레이 키보드로 선택"** → 선택창에서 고르기
3. 아무 입력창을 누르면 반폭 키보드가 뜸

## 스타일
두 가지 테마를 제공합니다. 라이트는 사진과 같은 순정 느낌(연회색 키·검정 글자), 다크는 테두리 없는 짙은 회색 계열입니다.

| | 라이트 | 다크 |
|---|---|---|
| 카드 | #F4F5F7 | #16191E |
| 키 | #E9EAEC | #2A2F37 |
| 글자 | 검정 | 흰색 |

## 배운 것 (시행착오)

### 1) 백스페이스가 "가끔" 안 됨 — 진짜 원인은 받침
한글 조합 상태를 내부에서 관리하다 보니, **앱이 조합을 먼저 확정**하면 내부 상태와 어긋나 아무 동작도 하지 않았습니다.

더 근본적인 버그는 **홑받침을 그대로 유지**한 것이었습니다. `안`을 지우면 `안`이 그대로 나와 "변화 없음 = 안 지워짐"으로 보였죠.

```
안 → 안   (버그)
안 → 아 → ㅇㅏ → 삭제   (수정 후)
앉 → 안 → 아 → ㅇㅏ → 삭제
값 → 갑 → 가 → ㄱㅏ → 삭제
```

**해결**: 내부 상태가 아니라 **화면에 실제로 보이는 글자**를 기준으로 한 단계씩 축소. 받침 → 모음 → 초성 → 삭제 순서.

### 2) 길게 누르면 손을 떼도 계속 지워짐
반복 작업을 뷰의 `setTag`에 넣어 관리해서, 연타하면 **이전 작업이 덮어써져 취소가 안 됐습니다.**

**해결**: 반복 작업을 **하나의 전역 핸들러**로 통합하고, 손을 떼거나 키보드가 닫히면 **무조건 중단**.

### 3) 투명도 100%인데 뒤가 비침
슬라이더로 카드 알파만 조절했는데, **키 색상 자체에 반투명값(90%, 30%)** 이 섞여 있어서 100%로 올려도 비쳤습니다.

**해결**: 모든 색상을 **완전 불투명(FF)** 으로 통일. 슬라이더가 실제로 유일한 투명도 제어가 되도록.

### 4) 오버레이 IME는 전체 폭 창 + 투명 배경
입력기(IME) 창 자체는 화면 전체 폭이어야 하는데, 그 위에 **투명 배경 + 절반 폭 카드**를 올리는 구조로 해결했습니다. 창 배경을 투명하게 만들고 `setDimAmount(0)`으로 주변 어둡게 하기를 꺼야 합니다.

## 참고
- 안드로이드 IME(InputMethodService) 기반이라 **시스템 키보드처럼 동작**합니다
- 폴스타4는 `targetSdk 22`라 별도 권한 승인 없이 바로 사용 가능
- 키보드 전환은 설정에서 언제든 원래 키보드로 되돌릴 수 있습니다
