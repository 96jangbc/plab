🌐 웹 오버레이

아무 웹사이트나 떠 있는 창으로 띄우는 범용 오버레이입니다. 북마크도 관리합니다.

이 앱은?

차에서 자주 보는 사이트를 빠르게 띄우고 싶을 때 씁니다. 추천 북마크가 기본으로 들어 있고, 내가 원하는 사이트를 추가/삭제할 수 있습니다.

주요 기능

  • 추천 북마크: 유튜브 · 네이버 · 치지직 · 티빙 · 웨이브
  • 직접 추가/삭제: 이름 + 주소 입력해 북마크 등록
  • 주소창에 아무 주소나 입력해 열기
  • 브라우저 모드 3종(기본/모바일 Chrome/PC Chrome) — 일부 사이트 차단 우회

사용법

  1. 앱 실행 → 오버레이 켜기
  2. 북마크 탭 → 바로 열림 / 주소 입력 → 열기
  3. "브라우저 모드 변경"으로 재생 안 되는 사이트 재시도
