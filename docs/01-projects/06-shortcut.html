🔗 숏컷 독

화면에 떠 있는 바로가기 독. 앱 아이콘을 모아 두고 탭 한 번에 실행합니다.

이 앱은?

자주 쓰는 앱을 열려면 매번 앱 목록을 찾아 들어가야 합니다. 이 앱은 즐겨찾기 앱을 독처럼 띄워, 한 번의 탭으로 실행하게 해줍니다.

주요 기능

  • 설치된 앱 목록에서 골라 독에 추가 / ✕로 삭제
  • 배열(세로×가로) 지정: 세로 1~8 × 가로 1~6 격자
  • 아이콘 + 이름 표시, 헤더 드래그 이동 · 핀치 크기조절

사용법

  1. 앱 실행 → "설치된 앱 불러오기" → 넣을 앱 탭
  2. "세로/가로 +−" 로 배열 맞추기
  3. 오버레이 켜기 → 독 버튼 탭 → 앱 실행

기술 포인트

  • 오버레이 권한이 있으면 다른 앱 실행(런처 인텐트) 가능
  • queryIntentActivities(MAIN/LAUNCHER) 로 앱 목록 조회
  • 칸보다 숏컷이 많으면 "+N (칸 부족)" 표시
