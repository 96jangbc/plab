📷 주차 스냅샷

P 기어에 넣으면 자동으로 사진을 찍어 텔레그램으로 보내 줍니다. 주차 위치(지도)까지 함께.

이 앱은?

주차 후 "내가 어디에 세웠는지" 잊을 때가 있습니다. 이 앱은 주차(Ｐ) 하면 차 앞을 사진으로 찍어, 나의 텔레그램으로 사진 + 위치(지도) 를 자동 전송합니다. 하차 직후 받아볼 수 있습니다.

주요 기능

  • P 기어 진입 감지 → 카메라 촬영 → 텔레그램 전송
  • 위치: 구글맵 링크 + 텔레그램 위치 핀
  • 오버레이에 기어·GPS·전송 상태 표시 (크기조절·이동 가능)
  • 수동 테스트 버튼 포함

사용법

  1. 텔레그램에서 봇(@BotFather로 생성)과 /start
  2. 앱에 봇 토큰·챗ID 입력(내장 기본값 있음) → 저장
  3. "오버레이 켜기" → P 넣으면 자동 촬영·전송

배운 것 (시행착오)

  • 차량 카메라: EVS(서라운드뷰) API는 시스템 전용이지만, Camera2 API로는 접근 가능 (실차 촬영 성공)
  • 도어 신호 차단: DOOR_POS는 Signature|Privileged 권한 → 서드파티 불가 → 트리거를 P 진입으로
  • 텔레그램 실패 3연타: ①봇과 대화 미시작(chat not found) ②차에서 토큰 오타(401) ③캡션 UTF-8 깨짐(400)
