🧭 기어 오버레이

화면 구석에 현재 기어(R/N/D/P) 를 크게 띄워 주는 작은 오버레이 앱입니다.

이 앱은?

폴스타4의 계기판은 기어가 눈에 잘 안 들어옵니다. 이 앱은 화면 위에 항상 떠 있는 작은 창으로 지금 기어가 무엇인지와 오토홀드(H) 상태를 보여줍니다. 변속할 때 알림음도 울려 줍니다.

주요 기능

  • 기어 표시: R · N · D · P (+ H = 오토홀드)
  • 변속 알람: 기어를 바꾸면 알림음 (내가 고른 음원)
  • 오토홀드(H): 브레이크를 놓아도 차가 잡혀 있는 상태를 H로 표시(형광노랑)
  • 창 이동(드래그) · 핀치 크기조절 · 크기 저장

사용법

  1. 앱 실행 → 권한(오버레이) 허용 확인 → 오버레이 켜기
  2. 헤더를 끌어 원하는 위치로 이동
  3. 두 손가락으로 벌려/오므려 크기 조절

기술 포인트

  • 차량 데이터는 리플렉션 Car API로 GEAR_SELECTION 조회 (raw 1=N 2=R 4=P 8=D)
  • 표준 API에 오토홀드 속성이 없어, 바퀴 회전 정지 + D/R로 H를 합성
  • 오버레이 창이 차 상단 상태바에 가리지 않도록 y를 강제
