🤖 OpenCode Go 모델 분석과 추천

코딩 에이전트용 구독 OpenCode Go(월 $10)에서 어떤 모델을 쓰면 좋을지 정리했습니다.

특히 상시로 돌아가는 AI 조력자(에이전트) 관점에서 "무엇이 효율적인가"를 기준으로 봤습니다.

효율의 기준

긴 세션에서 에이전트는 매 턴 컨텍스트를 다시 읽습니다. 그래서 실제 비용은 캐시 읽기 단가가 좌우합니다.

  1. 캐시 읽기 단가 (가장 중요)
  2. 월 한도 여유
  3. 이미지 지원 (스크린샷 분석)
  4. 컨텍스트 크기
  5. 한국어 품질
  6. 프라이버시 (학습 미사용 여부)

결론 (상황별)

  • 메인 · 상시 에이전트: deepseek-v4.1-flash — 캐시 최저 + 월 한도 $60 + 이미지 + 1M 컨텍스트
  • 코딩 작업: kimi-k2.7-code (코딩 특화, 월 한도 $60)
  • 자동화/대량: glm-5.3-flash 또는 mimo-v2.6-flash 로 한도 분산
  • 고난도 추론만: kimi-k3 · glm-5.3 (월 한도 $15라 아껴 쓰기)
  • 회피: muse-spark-1.2/1.3-contributor — 프롬프트가 모델 학습에 사용됨 ⚠️

프라이버시

  • 대부분 학습 미사용. DeepSeek는 ZDR(0일 보존), Grok/GPT/Claude는 30일 보존(악용 모니터링).
  • ⚠️ Muse Spark Contributor 는 프롬프트·결과가 Meta 학습에 사용됩니다(대신 초저가).

참고

  • 모델 ID 형식: opencode-go/<model-id> (예: opencode-go/kimi-k3)
  • 한도 규칙: 모델별 월 달러 한도 = 5시간 20% · 주 50% · 월 100%
  • 문서: <https://opencode.ai/docs/ko/go/>
